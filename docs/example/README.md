# OrderFlow example package

This folder is the canonical example of a complete assessment package for the kit.

## Complete package definition

A complete assessment package includes:

1. An executive assessment narrative.
2. Intake and business framing.
3. System inventory and hotspots.
4. Risk register with explicit evidence.
5. Quality-attribute scenarios with measurable outcomes.
6. A modernization roadmap tied to risks and rollback thinking.
7. At least one ADR linked to the recommendation.
8. A decision log that records status and review triggers.
9. A technical debt map linked to business impact and risks.
10. A traceability matrix that ties recommendations back to drivers and evidence.
11. An evidence register and glossary that make trace links auditable and consistent.
12. An assessment playbook that defines execution gates and stop rules.
13. A post-decision review that defines how decisions re-open when triggers fire.
14. Stakeholder and discovery inputs that ground the assessment in operational constraints.
15. Current-state and target-state architecture views that frame transition intent.
16. NFR baseline, measurement plan, and migration assumptions that anchor input quality.
